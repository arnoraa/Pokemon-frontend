Forside Pokemon Trainers Dashboard

Velkommen til vores Pokédex

Dette projekt er lavet som en del af vores tværfaglige midtvejsprojekt. Formålet er at udvikle en applikation, hvor brugeren kan udforske forskellige Pokémon, se deres stats, samt undsersøge forskellig information

Vi har brugt både HTML, CSS og Javascript til udarbejdelsen af frontend delen. Til backend har vi brugt node.js samt Express og så har vi brugt MySQL som database

Projektets funktioner

På vores hjemmeside kan du

  • Se og filtrere Pokémon
  • Se og adminstrere Trainers
  • Se hvilke Pokémon der er på lokationen Power Plant
  • Se nogle visualiserede statistikker i vores dashboard
